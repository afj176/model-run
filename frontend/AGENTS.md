Trace retention: `Application.publish` stores encoded bytes and groups traces by `run` (the frontend sends `run_group` and `run_step` per session step); eviction is by whole run, `restoreRun` in `Observatory.jsx` rebuilds the session from the server's grouping. Image and speech: `model_run/media_models.py` holds the loaders, `ImageClassifierAdapter` and `SpeechAdapter`; a Whisper run publishes `generation` and `module` traces in one run group so `restoreRun` shows the Response panel. Timeline dots use `layerStops` (paths), because layer numbers repeat across encoder/decoder and double/single stacks. Audio view: `_audio_view` in `media_models.py` records `trace.audio_view`; a token's map is the attention row of the position before it, because a decoder position predicts the next token. `SliceRecorder(sequence=...)` gives `layout: "sequence"` records with no axes. The standalone CSP needs `media-src data:` for playback; a page test of `.audio-play` catches a regression, setting `currentTime` does not. Views sit inside `ErrorBoundary` keyed on the trace id. A new Run always gets a new run group; only an attention-only re-probe reuses one. On the ComfyUI canvas, single-line STRING widgets open a Value dialog that needs OK, so scripted typing without it changes nothing. All layers: a blank Observe modules field uses `all_layer_paths` and `all_layer_plan` in comfy_bridge.py, which set each event's share of prefix and slice values; `SliceRecorder.text_tokens` drops text-first tokens in mixed blocks when the count fits, and `_token_sequence` reads audio and text streams. Tensor Volume: `volumeEvent` stacks recorded maps with height as an axis; video Compare diffs every frame through `comparableFrames` and `pixelDifference`, and only pairs frames both runs kept. Attention maps: `measure(stream="audio")` gives a 1 x T strip selected by `audio:N`, counted by geometry rather than call order; keys [text, image] with queries ending in the image cover Qwen-Image and HiDream-O1. Always run a no-mask control when reading a mask effect: same settings here are pixel-identical. LTX text keys are real tokens first, then registers (`place_registers`); the tokenizer's left padding does not describe them. When adding a model, check labels by masking a position and looking, because tokenizer output need not match key order. To check a new model's labels: swap one word and find the first position where `c_crossattn` changes; it must equal the labelled position on a left-to-right encoder. New ComfyUI model: run `tools/check_comfy_families.py`; a family whose text keys are not first needs `TEXT_LAST_MODELS` or a `register_tokens` lead in `comfy_bridge.py`, or its maps are silently wrong.
Layer pickers use the outermost numbered stack (`displayNodes` in `api.js`), matching `all_layer_paths` in `comfy_bridge.py`; `UNetModel` labels count as checked only for SD 1.5 and SDXL text sizes.
